# Day 13 Task – Countdown Timer

## Project Overview

A simple and responsive Countdown Timer built using HTML, CSS, and JavaScript. It displays the remaining days, hours, minutes, and seconds until a specific target date.

## Features

* Countdown updates every second.
* Configurable target date.
* Displays days, hours, minutes, and seconds.
* Completion message when the timer reaches zero.
* Automatically stops when the countdown ends.
* Responsive design for mobile and desktop.
* Attractive UI with hover effects.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Flexbox
* Media Queries
